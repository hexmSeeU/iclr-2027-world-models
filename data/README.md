# 论文数据

- `papers.json`：网站读取的完整结构化记录
- `papers.csv`：便于下载、排序和进一步整理的表格版本

这是从 AcceptOdds 的 ICLR 2027 公开记录中逐篇摘要筛选的主题目录，不是穷尽清单。检索时间、范围、候选数定义和限制保存在 JSON 的 `metadata` 中。

每项保留论文标题、来源链接、实际指向的 OpenReview 链接、相关性分类、主题标签和简要说明。`verifiedConference` 只表示是否已独立对照 OpenReview 核验标题与会议元数据，不代表论文接收。摘要简述与中文相关性说明为辅助阅读的转述；完整内容请回到原文。

更新时应同步两个文件，保留主来源链接并检查 ID 与论文链接唯一性。不收录赔率或将预测概率当成会议结果。
